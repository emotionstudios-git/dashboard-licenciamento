# Dashboard Licenciamento

Dashboard central de gestão de contratos, royalties, MG (mínimo garantido) e performance de licenciados — Oinc Filmes.

## Stack
- Frontend: Vite + React 19 + Tailwind 4
- Backend: Cloudflare Pages + Functions
- Database: D1 (SQLite)
- Auth: CF Access (controle por perfil)

## Desenvolvimento local

```bash
npm install
npm run dev  # http://localhost:5173
```
